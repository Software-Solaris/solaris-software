# BMP390

BMP390 barometric pressure and temperature sensor implemented as an SPP producer. Uses SPI communication and GPIO data-ready interrupts to acquire compensated pressure, temperature and relative altitude.

The first 500 measurements are used for reference calibration. Subsequent measurements are published through PUBSUB using a dynamically assigned KPID.

---

## Files

| File | Description |
|---|---|
| `bmp390.h` | Public API and `BMP390_t` context struct |
| `bmp390.c` | Driver implementation, calibration, compensation and producer callbacks |

---

## Registration

The BMP390 uses a static sensor instance and exposes its producer contract through:

```c
const SPP_SERVICE_ProducerContract_t *SPP_SERVICES_BMP390_getProducerContract(void);
```

The application registers this contract through `SPP_SERVICES_PUBSUB_registerProducer()` during FSM initialization.

The producer implements `init()` and `acquireData()` callbacks. Acquisition only proceeds when the GPIO data-ready flag is set.

---

## Packet payload layout (12 bytes)

| Offset | Type | Field |
|---|---|---|
| 0 | `float` | Altitude (m) |
| 4 | `float` | Pressure (Pa) |
| 8 | `float` | Temperature (°C) |

---

## Hardware configuration (ESP32-S3)

- SPI device index: 0 (CS GPIO 18, 500 kHz, MODE0).
- DRDY interrupt: GPIO 3, rising edge.
- ODR register: `0x01`.
- IIR configuration: `0x02`.
- Oversampling: `0x00`.
- Chip ID: `0x60`.
- Initial calibration: 500 samples.
